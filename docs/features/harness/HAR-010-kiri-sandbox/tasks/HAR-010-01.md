### Objective
Implement the foundational contracts, path canonicalization security guard, and 8,192-byte head/tail output bounding buffer for the Kiri execution sandbox. This guarantees that any path handled by the Harness is proven to be contained strictly within the scoped workspace root (blocking symlink escapes, parent directory traversal, and host secret paths like `~/.ssh` or `.env`), and that all process output is strictly bounded to prevent memory exhaustion in the agent journal.

### Starting point before this task
- `src/lib/harness/contracts.ts` defines `IHarnessWorkspace` and `HarnessWorkspaceRef`, but lacks low-level sandbox driver interfaces (`ISandboxDriver`, `SandboxExecutionOptions`, `SandboxExecutionResult`).
- Path validation is currently ad-hoc across fixtures and lacks symlink resolution via `fs.realpathSync`.
- Process stdout/stderr currently lacks a bounded head/tail truncation stream buffer.

### Implementation Scope
1. Define `ISandboxDriver` and execution option/result interfaces in `src/lib/harness/sandbox/contracts.ts`.
2. Implement `validateScopedPath(workspaceRoot: string, targetPath: string): string`:
   - Canonicalizes workspace root using `fs.realpathSync`.
   - Resolves target relative to root.
   - For existing files, validates `fs.realpathSync(resolved)` begins with `canonicalRoot + path.sep`.
   - For non-existent files (about to be created), validates canonical directory prefix.
   - Enforces blacklist blocking `.git`, `.env`, `.env.*`, `~/.ssh`, `~/.aws`, `~/.gnupg`, `/etc`, `C:\Windows`.
   - Throws typed `HarnessError` / `SandboxPathError` on traversal or blacklisted targets.
3. Implement `BoundedOutputBuffer`:
   - Configurable byte limit (default: 8,192 bytes).
   - Ingestion of `Buffer` or `string` chunks for stdout and stderr.
   - If total bytes exceeds limit, retains `limit / 2` bytes from head and `limit / 2` bytes from tail, with intermediate marker `... [X bytes truncated] ...`.
   - Tracks total bytes ingested, truncated boolean flag, and execution timing.
4. Export public interfaces from `src/lib/harness/sandbox/index.ts`.
5. Author test fixture in `scripts/test-kiri-sandbox-contracts.mjs` with ≥ 15 assertions.

- No path outside `canonicalRoot` may ever be returned by `validateScopedPath`.
- Blacklisted filenames (`.git`, `.env`) are rejected even if they are located inside the workspace root.
- The output buffer will never hold more than `maxBytes + markerLength` in memory per stream.

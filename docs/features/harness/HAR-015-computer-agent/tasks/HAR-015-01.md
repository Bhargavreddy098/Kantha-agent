# HAR-015-01 · Run a bounded Orgo computer agent

**Status** · IN_REVIEW

**Parent** · [Orgo computer-use agent](../SPEC.md)

Add an authenticated Gateway endpoint that uses an eligible vision and tool model to observe and interact with an operator-assigned Orgo desktop.

## Acceptance criteria

- Only the assigned workspace owner can use the computer.
- A task can observe the desktop, act on it, and return an answer based on a refreshed screenshot.
- Each model request has independent budget admission and settlement.
- Each desktop action is recorded before dispatch. A lost action acknowledgement terminates the run and reusing its run ID does not dispatch again.
- Existing Gateway and Harness entry points retain their behavior.

## Verification
